<a name="style preference">==============================================================================
Help on skill              :  Style preference
Guild Level                :  Bravo
Skill type                 :  Protection
Protection category        :  General
Average duration           :  Incredible
Number of stacks           :  1
Ep Cost                    :  420
Using time                 :  5 rounds
Affecting stats            :  con
Base Experience Cost       :  720
==============================================================================
This skill is the perfection of setting yourself into a style of kungfu.  By
setting your style you improve your abilities given to you by a specific style. 
If you do not set a style at all you will have problems using any of the higher
level skills.
Note - you can check what your current style is with the 'style' command.
This skill is affected by the skills Soul of the Tiger, Soul of the Toad, Soul
of the Crane, Soul of the Snake, Soul of the Dragon.
Use the following syntax   :  'use style preference with <style_name>.
This skill using time varies somewhat.
==============================================================================
Created By                 :  Pav-neto/Phire
==============================================================================


<a name="tiger claw">==============================================================================
Help on skill          :  Tiger claw
Guild Level            :  Bravo
Skill type             :  Attack
Average damage         :  High
Damage type            :  Physical
Ep Cost                :  284
Using time             :  4 rounds
Affecting skills       :  focus tiger claw
Affecting stats        :  dex
Base Experience Cost   :  1057
==============================================================================
The Tiger can learn to quickly strike at an opponent. Through extensive training
the Tiger can learn to use this skill to quickly deliver a blow to the most
vital area. Knowledge in the lightning strike skill allows the Tiger to deliver
faster blows at his opponent. 
Your martial stance affects the cost of this skill, and it is noticeably cheaper
if you have focused your chi, which allows you to act with more reservation.
This skill is affected by the skills Poison Claw, Double Claw Attack, Focus
Tiger Claw, and Sharpen Claw.
==============================================================================
Created By             :  Magneto
==============================================================================

<a name="double claw attack">==============================================================================
Help on skill          :  Double claw attack
Guild Level            :  Bravo
Skill type             :  Mastery
Base Experience Cost   :  1796
==============================================================================
Through extensive study, and some hard-worn battle experience, the Tiger style
user will learn how to double up on a Tiger Claw strike at his opponent. The

represents the ultimate in knowledge of how to critically wound an opponent with
the Tiger Claw attack.

Created By             :  Pavilion
