## 2. NAVIGATION — What's on the Left Sidebar?

Typical bsport backoffice sections (top to bottom):
- **Dashboard** — Revenue, attendance, booking stats. Customizable graphs.
- **Calendar** — Where you create classes, workshops, appointments. The heart of scheduling.
- **Schedule** — Staff availability, teacher schedules, room bookings.
- **Members** — CRM. Member list, tags, filters, imports.
- **Products** — Passes, subscriptions, memberships, workshops, gift cards.
- **Transactions** — Payments, refunds, invoices, failed charges.
- **Marketing** — Email campaigns, SMS, smartlists, automations.
- **Inbox** — Direct messages to/from members.
- **Reporting** — Detailed analytics (attendance, revenue by activity, etc.).
- **Settings** — Integrations (Stripe, Zoom, Kisi), notifications, roles, personalization.
- **My Studio** — Branding, app customization, establishment settings.
- **Access Control** — Kisi door integration, check-ins.

## 3. CREATE A CLASS (Calendar)

Path: Calendar > Click date > "Add an activity"

Fields you'll fill:
- **Activity type** — Choose from existing types or create new.
- **Date & Time** — Single or recurring (daily/weekly).
- **Teacher** — Assign staff member.
- **Room/Establishment** — Where it happens.
- **Capacity** — Max participants.
- **Level** — Beginner, intermediate, advanced (optional).
- **Credits** — How many pass credits this class costs.
- **Price** — If not covered by membership.
- **Description** — What members see.

> **GOTCHA:** You cannot assign 2 teachers to 1 class. Affects payroll if you need co-teaching.

---

## 4. FIND A MEMBER (Members)

Path: Members > Search bar

Search by:
- Name, email, phone
- Tags (e.g., "Staff", "VIP", "Beginner")
- Membership type
- Pass type

Member profile shows:
- Contact info
- Active passes/subscriptions
- Booking history
- Attendance rate
- Tags
- Notes

---

## 5. SET UP A PASS OR SUBSCRIPTION (Products)

Path: Products > Passes (or Subscriptions)

**Passes** (pay-as-you-go):
- Name, description
- Number of credits
- Validity period (e.g., 30 days, 90 days)
- Price
- Which activities it applies to

**Subscriptions** (recurring membership):
- Name, description
- Billing frequency (monthly, yearly)
- Price
- Cancellation terms
- Which activities included
- Pause rules

> **GOTCHA:** bsport is modular — you pay per feature. Marketing, client app, payment integrations are add-ons. Don't be surprised if some features need unlocking.

---

## 6. SEND AN EMAIL (Marketing)

Path: Marketing > Smartlists > Create Smartlist > Send Mail

Steps:
1. Create a Smartlist (filtered member group)
   - Filters: Tags, membership type, attendance, last visit date, etc.
2. Click "Send mail" on the Smartlist
3. Choose template or write new
4. Preview and send

> **GOTCHA:** Email deliverability — you may need to set up CNAME DNS records with your domain provider (OVH, GoDaddy, etc.) to avoid spam folders. bsport team sends you the codes.

## KEY GOTCHAS FROM REVIEWS

1. **Two teachers per class:** Not possible. Plan accordingly.
2. **"Pay later" option:** Members can book without paying online. They pay in-studio. You'll mark as "Manual Payment."
3. **Email unsubscribes:** Some users report unsubscribed people still getting emails. Check Smartlist filters carefully.
4. **Payout delays:** Some studios report delays in receiving payouts. Factor into cash flow.
5. **Support hours:** Weekdays 8AM–5PM only. Weekend issues wait until Monday.
6. **Modular pricing:** Features are add-ons. Your base package may not include Marketing or Branded App.
