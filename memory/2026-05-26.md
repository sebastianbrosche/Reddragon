## Evennia Server Deployment Pattern Established
**Reliable deploy pipeline for Red Dragon MUD on Hetzner:**

1. Write file locally to `/tmp/filename.py`
2. `scp -o StrictHostKeyChecking=no /tmp/filename.py root@178.105.198.32:/opt/reddragon/reddragon/path/`
3. `sshpass -p 'RedDragon2026!' ssh -o StrictHostKeyChecking=no root@178.105.198.32 'cd /opt/reddragon/reddragon && evennia reload'`
4. Wait for "Server reloaded." confirmation

**Server:** `178.105.198.32:3000` (telnet), port `8000` (web client)
**Admin:** `darkstaff` / `1234`
**Test:** `tester99` / `1234abcd`
**Reload:** `evennia reload` (never `evennia stop` — kills the daemon)
