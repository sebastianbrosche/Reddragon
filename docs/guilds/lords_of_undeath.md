<a name="lich transformation">==============================================================================
Help on spell          :  Lich transformation
Guild Level            :  Omicron
Spell type             :  Special
Sp Cost                :  1170
Casting time           :  30 rounds
Affecting skills       :  anatomy
Base Experience Cost   :  2366
==============================================================================
This spell will initiate a lich transformation in the caster. If successful the
caster will when the transformation is complete become a lich. As a lich all of
the necromancers abilities will be more powerful, however the actual
transformation takes time and the necromancer must eat certain ingredients in
order to keep the transformation going on until completion. While the caster is
undergoing the transformation the caster will be weakened and so will all of his
necromantic abilities. It is said that necromancers with higher amount of
mastery points is better able to use the parts which they are forced to eat and
so able to complete the transformation faster.
==============================================================================
