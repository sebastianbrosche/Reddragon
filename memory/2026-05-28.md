
## Movement System Fixed (2026-05-27 ~23:00)

**Problem:** Characters `testcombat1` and `darkstaff` had `location=None` (limbo), so movement commands returned "Command not available."

**Fix:** Ran inline Python on Hetzner server to move both characters to `Adventurer Guild Entrance` (room id=3) and set `.home` there.

**Result:** All directional movement now works:
- `east`/`e` → Adventurers Leveling Place
- `west`/`w` → Plaque Rooms (from Guild Entrance)
- `south`/`s` → Myth Room
- `north`/`n` → Cloud Road
- `northeast`/`ne` → Silent Room
- `southwest`/`sw` → Portal Room

**Root Cause 1:** `CmdMove` was silently removed from `CombatCmdSet` by Evennia command deduplication because it shared alias `"w"` with `CmdWho`. Hash anomaly confirmed: `hash(CmdMove()) == hash(CmdName())` and `CmdMove() == CmdWho()`.

**Fix:** Removed `self.add(CmdMove)` from `CombatCmdSet` in `/opt/reddragon/reddragon/commands/combat.py`. Exit objects handle movement natively; CmdMove was redundant.

**`w` alias behavior:** In rooms WITH a west exit, movement wins. In rooms WITHOUT a west exit, `who` wins. This is correct MUD behavior.

## Guild System Fixed (2026-05-27 ~23:30)

**Problem:** `TypeError: argument of type 'NoneType' is not iterable` in `/opt/reddragon/reddragon/commands/guild.py` line 125.

**Cause:** `caller.db.guild_history` was `None` instead of `{}`.

**Fix:** Changed `getattr(caller.db, 'guild_history', {})` to `getattr(caller.db, 'guild_history', {}) or {}`.

**Verified commands:**
- `guilds` → displays all 13 guild trees
- `join warrior` → joins guild, sets level 1
- `score` → shows "Warrior (Level 1)" in header
- `advance` → shows XP needed for next level
