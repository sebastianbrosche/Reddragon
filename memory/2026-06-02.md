## KidsLingo / Word Dungeon — HTML Prototype (2026-06-02 afternoon)

**Status:** COMPLETE — single-file playable prototype delivered.

### Location
`/root/.openclaw/workspace/kids-language-game/index.html`

### Core Loop (from user feedback)
1. Fight monsters in dungeon → they speak in **image-word sentences** (e.g., ANGRY + RED + BALL + RUN)
2. Player picks correct meaning from 4 options
3. Correct answer damages monster; wrong answer damages player
4. After defeating monsters, enter **Safe Room (Guild Hall)**
5. **Mordecai the rat Guildmaster** quizzes you on words learned
6. Open **loot boxes** (only in safe zone)
7. Exit via **gold glowing stairwell** when floor complete

### Features Implemented
- **Monster speech bubbles** with emoji icons + hidden text (??? until learned)
- **Turtle speech control** 🐢 — click to toggle TTS speed (0.5x → 0.7x → 1x → 1.5x)
- **Karaoke syllable highlighting** — word splits into syllables (BA-NA-NA), each highlights as spoken with progress bar
- **Custom words input** — paste word list, auto-matches emojis from 200+ word library, falls back to first-letter defaults
- **5+ hour floors** — configurable monsters-per-floor (default 20), progress tracker
- **Gold stairwell exit** — appears in safe room after floor complete, glows with `filter: drop-shadow()` animation
- **3 default levels** (Colors, Animals, Food) + custom floor
- **Inventory system** — Awards, Boxes, Words tabs
- **Web Audio API sound effects** — correct/wrong/loot/click/stairwell tones, no external files
- **Save/load via localStorage**
- **Mobile-first, touch-optimized**
