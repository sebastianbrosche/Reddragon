## IOM Autopilot — SEMICOLON DISCOVERY (2026-05-22 06:02)

**CRITICAL LESSON:** Semicolons (`;`) do NOT work as command separators in Islands of Myth.

**What happened:**
- Generated semicolon-chained commands: `n;l;n;l;n;l...`
- Relay sent them to IOM
- IOM treated the entire string as a single unknown command
- Result: Hundreds of "TYPO" messages from the MUD:
  - "Are you typing with your toes?"
  - "FARGIN [ T_Y_P_O ] !"
  - "The Gamedriver looks at you with a look of utter bafflement."
  - "Ok, deleting your playerfile... Done!" (joke message)
  - "Mr. T walks up to you and says, 'I pity the fool that doesn't know how to type!'"
  - "Zifnab nabs your TYPO before you can re-enter it!"
- NO actual movement occurred during semicolon batch
- Session log shows character stayed in same room, only typo messages flooded

**User corrections:**
- "no, it doesnt work."
- "forget the ; semicolon. it doesnt work"
- "stop using semicolon"
- "just use one command per enter"

**Fix applied:**
- Killed old relay (PID 141176) that was sending semicolons
- Generated new queue with ONE command per line (1934 commands)
- Restarted relay (PID 143972)
- Queue: `/tmp/iom-autopilot-queue.txt` with single commands (n, l, s, l, w, l, etc.)

**Current status:**
- Relay connected to IOM login screen
- Sebbe NOT logged in (disconnected during typo storm?)
- Waiting for login credentials
- Two WebSocket clients connected from localhost

**Next time:**
- NEVER use semicolons in IOM commands
- Each movement + look = 2 separate lines in queue
- `n` then `l`, not `n;l`
- Same for all directions: `e`, `s`, `w`, `ne`, `nw`, `se`, `sw`, `n`, `s`
