### 3. Command History — Already Exists in Custom Client (verified)

### 4. UnloggedinCmdSet Crash — Fixed (22:13)
File: `commands/default_cmdsets.py`
- Wrapped ALL optional imports in try/except so cmdset never fails to load
- Problem: `commands.raceguild_cmds`, `combat_cmds`, `system_cmds`, `system_cmds_part2` were failing to import (likely due to missing modules), causing the entire CharacterCmdSet to crash, which cascaded to UnloggedinCmdSet fallback
- Evennia was falling back to default unloggedin commands, which had password restrictions and different behavior
- Fixed by making all imports optional with `None` fallbacks, only adding commands if import succeeded

### 5. Name Restrictions — Relaxed (22:26)
File: `commands/iom_login.py`
- Old regex: `^[a-zA-Z0_9_\-]+$` — only letters, numbers, underscores, hyphens
- New regex: `^[\x20-\x7E]+$` — all printable ASCII characters (spaces, symbols, anything)
- Removed length check (was 2-30 chars) — now allows any length printable name
- User wants total freedom: "you can call yourself anything"

### 6. Puppet Error — Fixed (22:26)
File: `commands/iom_login.py` (CmdIOMCreate)
- After creating character and account, old code did:
  - `account.db._playable_characters = [char]` — non-standard, doesn't trigger puppet
- New code does:
  - `account.db._playable_characters = [char]` — keeps list
  - `account.puppet_object(session, char)` — immediately puppets the new character
  - `char.locks.add("puppet:id(%i) or pid(%i) or pcd(%i) or all()" % (char.id, account.id, account.id))` — grants puppet permission
- This eliminates the "You don't have permission to puppet" and "You are out-of-character (OOC)" messages
- User spawns directly into the game world, not OOC limbo
