Members of the master enchanter guild learns how to add permanent enchantments to weapons and armors. They also learn how to disenchant armors and weapons into magical essences which they can use to enchant items.</p><p>Use the 'enchantinfo' command to get information about enchants that you know.</p><p>To learn new enchants from patterns you do 'use <pattern>'.</p><p></p><pre>


<a name="create enchantment stone">==============================================================================
Help on spell          :  Create enchantment stone
Guild Level            :  Omicron
Spell type             :  Special
Sp Cost                :  584
Casting time           :  15 rounds
Affecting skills       :  weapon enchanting, armor enchanting, mastery of
enchanting
Base Experience Cost   :  1183
==============================================================================
With this spell a master enchanter can create a small enchantment stone. The
stone will have different qualities depending on how the enchanter made it. 
Syntax                 :  cast create enchantment stone with <enchantment>
==============================================================================
Created By             :  Snoop
==============================================================================


<a name="disenchant armor">==============================================================================
Help on spell          :  Disenchant armor
Guild Level            :  Omicron
Spell type             :  Special
Sp Cost                :  350
Casting time           :  6 rounds
Affecting skills       :  mastery of enchanting, armor enchanting
Affecting stats        :  int, wis
Base Experience Cost   :  1360
==============================================================================

of magic and use that to create enchants. The item that is disenchanted will be
destructed.
