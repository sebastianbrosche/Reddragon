## IOM Web Client — BUILT (2026-05-21 21:30)

**What:** Browser-based MUD client for Islands of Myth so Sebastian can play without copy-pasting text to me.

**Architecture:**
- `mud-relay.py` (Python) — WebSocket ↔ telnet bridge running on server
- `mud-client.html` (Browser) — Dark terminal UI with quick command buttons
- Cloudflared tunnel exposes WebSocket relay publicly
- All MUD output logged to `/tmp/iom-session.log` for Miha to read

**Client URL:** https://1094710d.rcp-housing.pages.dev/mud-client.html
**WebSocket Relay:** wss://tone-staffing-fred-reducing.trycloudflare.com

**Features:**
- Real-time MUD output display
- Command input (Enter to send)
- Quick buttons: look, score, inventory, who, help, n/s/e/w, warp
- Auto-reconnect on disconnect
- Sidebar with command reference
- Miha can read session log to see what Sebastian sees

**How it works:**
1. Browser connects to relay via WebSocket
2. Relay connects to islandsofmyth.org:3000 via telnet
3. Everything IOM sends is forwarded to browser AND logged to file
4. Sebastian types commands, they go straight to IOM
5. Miha reads `/tmp/iom-session.log` to observe

**Note:** Cloudflared tunnel URL is temporary (changes on restart). For permanent use, set up a named Cloudflare Tunnel or open port 8765 on Alibaba security group.
