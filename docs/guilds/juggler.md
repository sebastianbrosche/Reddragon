Juggler guild members learn the art of throwing knifes. They learn to master the basic art in fighting with throwing knifes and how to effectively aim to a specific vital body part of their targets. They also learn where weak spots are in different kinds of armor and also learn the different anatomies to be able to do the most damage possible.</p><pre>


<a name="throw knife">==============================================================================
Help on skill          :  Throw knife
Guild Level            :  Gamma
Skill type             :  Attack
Average damage         :  Above average
Damage type            :  Physical
Ep Cost                :  144
Using time             :  1 round
Affecting skills       :  armor piercing, throwing art
Affecting stats        :  dex
Base Experience Cost   :  1075
==============================================================================
With this skill, a rogue can use a knife or dagger to throw it at an opponent,
thus damaging him. There is a chance that the weapon thrown will be destroyed
when it hits its target. Use of this skill requires a perfectly balanced knife
or dagger.
==============================================================================
Created By             :  Pavilion, Zifnab
==============================================================================

<a name="target preference">==============================================================================
Help on skill          :  Target preference
Guild Level            :  Gamma
Skill type             :  Miscellaneous
Ep Cost                :  174
Using time             :  1 round
Base Experience Cost   :  1008
==============================================================================
This skill is used with knife throwing skills. You may set a particular target
area to throw at. An accurate hit allows doing such things as stopping monsters
from tracking you, stopping players from running, doing extra damage with a head
or neck hit, or possibly even getting a fatal blow in the heart. Syntax to use
this skill is 'use target preference with <location>.
Valid locations are 'legs', 'shoulder', 'eyes', 'neck' or 'heart'.
==============================================================================
Created By             :  Zifnab
==============================================================================
