Barbarian guild members are taught to master the use of blunt type weapons. Barbarians learn to wield blunt weapons with strength and ferociousness. They learn to land solid blows, increase the chances of landing stunning attacks, and draw on their inner rage and fury to bludgeon their foes into pulp.</p><pre>


<a name="deathblow">==============================================================================
Help on skill          :  Deathblow
Guild Level            :  Bravo
Skill type             :  Attack
Average damage         :  Important
Damage type            :  Physical
Ep Cost                :  320
Using time             :  4 rounds
Affecting skills       :  bloodlust, blunt weapons mastery
Affecting stats        :  str
Base Experience Cost   :  1498
==============================================================================
This skill is the ultimate in bludgeoning techniques.  The warrior
who is skilled in it can muster up all of his (or her) emotions and
strength, combining them into one devastating attack.  When done
properly, there is even a chance the blow will damage some vital
organ in the target, causing instant death.
==============================================================================
Created By             :  Sven
==============================================================================

<a name="devastating attack">==============================================================================
Help on skill          :  Devastating attack
Guild Level            :  Bravo
Skill type             :  Combat
Base Experience Cost   :  1748
==============================================================================
This skill trains a fighter to use his weapon to deliver painful attacks
whenever the opportunity occurs. Whenever the warrior finds an opening in his
opponent defence and scores a critical hit, he will be able to deliver an even
stronger hit by reacting very fast and strenghtening his attack.
==============================================================================
Created By             :  Sigwald
==============================================================================

<a name="bloodlust">==============================================================================
Help on skill          :  Bloodlust
Guild Level            :  Bravo
Skill type             :  Mastery
Base Experience Cost   :  1960
==============================================================================
This skill allows bludgeon wielders to focus their hatred and rage. The end
result is that they can deliver blows using an awesome amount of power and doing
a severe amount of damage.
==============================================================================
Created By             :  Sven
==============================================================================
It can be trained up to 20 percent of your skill max at level 6.
It can be trained up to 40 percent of your skill max at level 7.
It can be trained up to 60 percent of your skill max at level 8.
It can be trained up to 80 percent of your skill max at level 9.
It can be trained up to 100 percent of your skill max at level 10.
==============================================================================


<a name="whirlwind strike">==============================================================================
Help on skill          :  Whirlwind strike
Guild Level            :  Bravo
Skill type             :  Area
Average damage         :  High
Damage type            :  Physical
Ep Cost                :  362
Using time             :  4 rounds
Affecting skills       :  bloodlust, enhance striking
Affecting stats        :  str, dex
Base Experience Cost   :  1249
==============================================================================
This is one of the most advanced offensive skill a fighter can learn. Using
amazing speed and strength, he can make a whirlwind fury with his weapon that
will strike all of his opponents around. Proper use of this skill requires a
blunt type weapon.
Being in a stance befitting a berserker has been known to allow the user to
increase their damage.
Proper mastery of blunt weapons is imperative to efficient usage of this skill.
This skill using time varies somewhat.
==============================================================================
Created By             :  Sigwald
==============================================================================


<a name="blunt weapons mastery">==============================================================================

Guild Level            :  Bravo
Skill type             :  Combat
Base Experience Cost   :  1345
==============================================================================

==============================================================================
Created By             :  Sigwald
==============================================================================
