Guild Level            :  Beta
Skill type             :  Miscellaneous
Ep Cost                :  20
Using time             :  1 round
Base Experience Cost   :  705

<a name="fire building">==============================================================================
Help on skill          :  Fire building
Guild Level            :  Beta
Skill type             :  Miscellaneous
Ep Cost                :  350
Using time             :  4 rounds
Base Experience Cost   :  604
==============================================================================
This skill allows a player to create a campfire for warmth.

are even able to start campfires without a tinderbox.
==============================================================================
Created By             :  Unknown
==============================================================================

<a name="camping">==============================================================================
Help on skill          :  Camping
Guild Level            :  Beta
Skill type             :  Protection
Protection category    :  General
Average duration       :  Low
Number of stacks       :  1
Ep Cost                :  262
Using time             :  5 rounds
Affecting skills       :  survival lore
Base Experience Cost   :  705
==============================================================================
This skill allows a player to make a camp and get some rest. This will speed up
the healing and regeneration of the player. Proper use of this skill requires a
sleeping bag. Once asleep though, the player does not wake up unless attacked
(or, obviously, when they are done resting).
==============================================================================
Created By             :  Sigwald
==============================================================================


<a name="herb gathering">==============================================================================
Help on skill          :  Herb gathering
Guild Level            :  Beta
Skill type             :  Miscellaneous
Ep Cost                :  262
Using time             :  15 rounds
Base Experience Cost   :  873
==============================================================================
This skill allows an experienced traveler to search for rare herbs
that can provide some healing when properly used. Knowledge of the
skill herb preservation is essential to keep the herbs active over
an extended period. Herbalists with herb lore skills are also more
efficient at gathering herbs.
==============================================================================
Created By             :  Sigwald
==============================================================================


<a name="herb preservation">==============================================================================
Help on skill          :  Herb preservation
Guild Level            :  Alpha
Skill type             :  Mastery
Base Experience Cost   :  501
==============================================================================
Knowledge of herbs is essential in order to preserve the powers of herbs
gathered in Nature. Students of this skill learn how to best keep herbs in order
to have them efficient over extended durations.
==============================================================================
Created By             :  Sigwald
==============================================================================
It can be trained up to 50 percent of your skill max at level 9.
It can be trained up to 100 percent of your skill max at level 10.
==============================================================================


<a name="awareness">==============================================================================
Help on skill          :  Awareness
Guild Level            :  Bravo
Skill type             :  Mastery
Base Experience Cost   :  1633
==============================================================================
This skill allows a player to be more aware of his environment.
As such, he is more likely to catch a rogue in the middle of a 
criminal act.
==============================================================================
Created By             :  Pavilion
