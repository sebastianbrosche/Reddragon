Skill type             :  Mastery

<a name="migrate">==============================================================================
Help on skill          :  Migrate
Guild Level            :  Omicron
Skill type             :  Miscellaneous
Ep Cost                :  462
Using time             :  4 rounds
Affecting skills       :  unnatural instincts, natural instincts
Base Experience Cost   :  1512
==============================================================================
It takes a lot of energy to migrate in the huge intercontinental patterns of the
true birds a shapeshifter imitates.  And the mating habits of dragons require
one to migrate nearly the entire length and breath of Islands of Myth. It is
only after years of strength and endurance building, and seasons of learning to
navigate by the various strange and inhuman ways by which the beasts of the
world find their way, that a shapeshifter is able to imitate these practices.

The syntax to use this skill is "use migrate with <bird type>".  Known migrating
birds include goose, kingfisher, owl, swallow, sparrow, warbler, duck, skylark,
sandpiper, thrush, bittern.
==============================================================================
Created By             :  Daneel
==============================================================================
