### 3. HOW IT WORKS — THE ASSEMBLY SEQUENCE
**IKEA-style numbered steps with icons:**

**01 | Foundation**
- Earth screws installed in 1 day by 1 operator
- No concrete. No excavation. No curing time.
- Fully removable and reusable
- Cost: €2,000-€3,000

**02 | Fabricate Wall Panels**
- EPAL pallets + OSB3 skins + Sikaflex adhesive
- Built on a simple jig on the ground
- One panel = one person, one hour
- 26 panels for a starter home

**03 | Erect Walls**
- Two people carry each panel
- Screws only — no cuts, no specialists
- Weathertight shell in 1-2 days

**04 | Floor System**
- 2x6 timber joists on earth screws
- P5 T&G chipboard deck
- Marine salt layer = biological protection

**05 | Roof**
- CE-marked I-joists with pre-rigged ridge plate
- One-time pallets as ceiling (pre-painted on ground)
- Steel sheet with pre-bonded condensation mat
- No scaffolding required

**06 | Insulate**
- Blown-in rockwool (contractor, 1 day)
- U-value: 0.40 W/m²K (4-5x better than Portuguese masonry)
- Cost: €2,000-€3,000 for full house

**07 | Interior Finish**
- Gypsum Type F (fire-rated)
- End-grain wood floor "cobblestones"
- Your choice: MVP or Eco-Luxury

**08 | Off-Grid Package**
- Solar PV + battery (€3,999)
- Solar hot water (€1,499)
- Composting toilet (€850)
- Smart home hub (€125)
- Total: ~€8,173

## TECH STACK RECOMMENDATION

**Option A: Static Site (Fast, Cheap, Maintainable)**
- Framework: Next.js or Astro
- Hosting: Cloudflare Pages (free, fast CDN)
- Styling: Tailwind CSS
- Calculator: React component with local state
- Forms: Cloudflare Workers + Email
- PDF downloads: Static files
- Images: Cloudflare R2 or Cloudinary

**Option B: Full Web App (More Interactive)**
- Same as above + database for:
  - User accounts
  - Build submissions
  - Community gallery
  - Workshop bookings
- Database: Supabase (PostgreSQL, free tier generous)

**Recommendation:** Start with Option A. The calculator and all content work perfectly as a static site. Add user accounts later if the community grows.
