<a name="confuse opponent">==============================================================================
Help on skill          :  Confuse opponent
Guild Level            :  Gamma
Skill type             :  Attack
Average damage         :  Almost nothing
Damage type            :  Physical
Ep Cost                :  70
Using time             :  3 rounds
Affecting stats        :  cha
Base Experience Cost   :  672
==============================================================================
This skill permits a Trickster to whisper some arcane deception into the ear of
an enemy, making them attack themselves briefly.
Charisma is VERY important in regards to how often the opponent will be
confused, as well as how long it will remain confused,  as is the proficiency
with deception of all kinds and specific proficiency with this skill.
==============================================================================
Created By             :  Cebcurg
==============================================================================
