Protectors Of The Earth guild members are taught how to create more powerful protection shields than the shields they learned to create in Abjurer. They learn to master the damage types of fire, cold, acid, and physical.</p><pre>


<a name="greater fire shield">==============================================================================
Help on spell          :  Greater fire shield
Guild Level            :  Gamma
Spell type             :  Protection
Sp Cost                :  350
Casting time           :  8 rounds
Protection category    :  Major
Average duration       :  High
Number of stacks       :  1
Affecting skills       :  protection ritual
Affecting stats        :  wis
Base Experience Cost   :  603
==============================================================================
A barrier of magic forms over the target making it much more resistant to fire
damage. Spell efficiency is affected by spell percent, level, wisdom and mastery
skill.
This spell casting time varies somewhat.
==============================================================================
Created By             :  Onyx and Aristide
==============================================================================


<a name="remove shields">==============================================================================
Help on spell          :  Remove shields
Guild Level            :  Gamma
Spell type             :  Special
Sp Cost                :  402
Casting time           :  6 rounds
Base Experience Cost   :  663
==============================================================================
The abjurer can cast this spell upon a target in order to remove protecting
shields from it. This spell can be cast only if the target stands very still,
which makes it impossible to use in battle.
