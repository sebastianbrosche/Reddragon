Master Navigators guild members take the fundamental knowledge of teleportation that they learned in the Navigator guild, and learn more powerful spells. They learn to cast powerful spells that can create portals to all the different islands and different spells to relocate and summon their friends and companions all at once. They also learn to create a marker beacon that they can leave somewhere in the world, which can allow the navigator to teleport himself back to later on.</p><pre>


<a name="party heavy weight">==============================================================================
Help on spell          :  Party heavy weight
Guild Level            :  Bravo
Spell type             :  Special
Sp Cost                :  560
Casting time           :  4 rounds
Affecting skills       :  mastery of navigation
Base Experience Cost   :  760
==============================================================================

to use that knowledge to learn how to prevent unwanted summonings.

<a name="call beacon">==============================================================================
Help on spell          :  Call beacon
Guild Level            :  Bravo
Spell type             :  Special
Sp Cost                :  654
Casting time           :  3 rounds
Affecting skills       :  mastery of navigation
Affecting stats        :  wis, int
Base Experience Cost   :  1056
==============================================================================
The caster uses this spell to summon a beacon. Upon creation,
the caster forms a mental link with his beacon that allows him
to relocate to it. Since the beacon is actually phased
out of our world, it cannot be moved.
==============================================================================
Created By             :  Magneto and Pavilion
==============================================================================
