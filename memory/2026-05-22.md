### Architecture
```
Browser (mud-client.html)
    ↕ wss:// (cloudflared temporary tunnel)
Cloudflare Tunnel (http://localhost:8765)
    ↕ ws://localhost:8765
Python Relay (mud-relay.py)
    ↕ telnet
Islands of Myth (islandsofmyth.org:3000)
```

## IOM Web Client v4 — AUTOPILOT MODE (2026-05-22 02:22)

**New relay:** `mud-relay-v2.py` with autopilot queue support
**Client URL:** https://d5df5078.rcp-housing.pages.dev/mud-client.html
**Tunnel:** wss://hartford-annie-insulation-dev.trycloudflare.com

**Autopilot Architecture:**
- Miha writes commands to `/tmp/iom-autopilot-queue.txt`
- Relay reads queue and sends to IOM when user is inactive
- Random delays 1.5-3.5s between commands (human-like)
- User command = autopilot pauses 120 seconds
- `resume` = autopilot resumes immediately
- `bot stop` = autopilot stops until resumed

**How it works:**
1. User logs into character via browser client
2. Tells Miha "explore 10 rooms" or "map this area"
3. Miha reads `/tmp/iom-session.log` to see current state
4. Miha queues exploration commands (look, n, s, e, w, etc.)
5. Relay executes them one by one
6. User watches, can interrupt anytime by typing
7. All output logged for Miha to read and build maps

**Server processes:**
- `python3 /root/.openclaw/workspace/rcp/mud-relay-v2.py` — relay with autopilot
- `cloudflared tunnel --url http://localhost:8765` — public WebSocket
