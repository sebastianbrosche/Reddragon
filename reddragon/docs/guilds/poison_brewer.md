<a name="brew confusing poison">==============================================================================
Help on skill          :  Brew confusing poison
Guild Level            :  Gamma
Skill type             :  Miscellaneous
Ep Cost                :  350
Using time             :  8 rounds
Affecting skills       :  mastery of poisons
Affecting stats        :  int, dex
Base Experience Cost   :  672
==============================================================================
This skill teaches knowledge of various plants and components
that will allow a brewer to create a poison that will confuse
the mind of an opponent, reducing his mental abilities.
To use this skill, a brewer needs an herb pot to mix herbs, and
an empty flask to store the mixture he prepared.

<a name="apply poison">==============================================================================
Help on skill          :  Apply poison
Guild Level            :  Gamma
Skill type             :  Enchantment
Protection category    :  Minor
Average duration       :  High
Number of stacks       :  1
Ep Cost                :  314
Using time             :  4 rounds
Affecting skills       :  mastery of poisons
Affecting stats        :  int, dex
Base Experience Cost   :  873
==============================================================================
It is essential for proper use of poison in combat to be able
to properly coat a weapon with poison. Without proper knowledge
of this skill, poison will just slip very quickly or fade. High
skill will allow a poison brewer to make the best use possible
from the poison he created.
Proper syntax is 'use apply poison at <weapon> with <poison>'
==============================================================================
Created By             :  Sigwald
==============================================================================
