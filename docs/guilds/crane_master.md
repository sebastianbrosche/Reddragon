Guild Level            :  Bravo
Skill type             :  Combat

<a name="style preference">==============================================================================
Help on skill              :  Style preference
Guild Level                :  Bravo
Skill type                 :  Protection
Protection category        :  General
Average duration           :  Incredible
Number of stacks           :  1
Ep Cost                    :  420
Using time                 :  5 rounds
Affecting stats            :  con
Base Experience Cost       :  720
==============================================================================
This skill is the perfection of setting yourself into a style of kungfu.  By
setting your style you improve your abilities given to you by a specific style. 
If you do not set a style at all you will have problems using any of the higher
level skills.
Note - you can check what your current style is with the 'style' command.
This skill is affected by the skills Soul of the Tiger, Soul of the Toad, Soul
of the Crane, Soul of the Snake, Soul of the Dragon.
Use the following syntax   :  'use style preference with <style_name>.
This skill using time varies somewhat.
==============================================================================
Created By                 :  Pav-neto/Phire
==============================================================================
